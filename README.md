# Task Manager Web Application

## Project Description

Task Manager Web Application is a Python-based web application developed using Flask and SQLite. The application allows users to register, log in, manage their daily tasks, and log out securely. It provides a simple and user-friendly interface for organizing and tracking tasks efficiently.

## Features

* User Registration
* User Login Authentication
* Add New Tasks
* View Existing Tasks
* Delete Tasks
* User Logout
* SQLite Database Integration

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

### Step 1: Install Flask

pip install flask

### Step 2: Run the Application

python app.py

### Step 3: Open Browser

Visit:

http://127.0.0.1:5000

## Application Workflow

1. Register a new account.
2. Login using your credentials.
3. Add tasks to your task list.
4. View all saved tasks.
5. Delete completed tasks.
6. Logout securely.
